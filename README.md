# 사주보는 3층 다락방 — 990원 온라인 사주 웹서비스

당근 비즈프로필(`사주보는 3층 다락방`)과 **완전히 분리된** 990원 온라인 사주 전용 정적 웹앱입니다.
가입 없이 생년월일시만 넣으면 만세력·자미두수로 원국을 계산해 무료 맛보기를 보여주고,
유료 리포트(1구슬 = 990원)는 맛보기 후 잠금 해제 방식으로 엽니다.

```
npm install
npm run dev        # http://localhost:5173
npm run test       # 만세력·자미두수 엔진 + 12간지·10종 상품 + 최애궁합 + 약관·구슬 안내 테스트 (44건)
npm run build      # dist/ 생성 — Vercel · Cloudflare Pages · GitHub Pages 어디든 그대로 배포
npm run shot       # 빌드 결과를 로컬 서버로 띄우고 검수용 스크린샷 생성 (playwright 필요)
npm run shot:v4    # 운세 10종 그리드 · 12간지 캐릭터 검수 — downloads/darakbang-web-*-v4.png
npm run shot:v3    # 다크모드(v3) 검수 스크린샷 — downloads/darakbang-web-*-v3.png
npm run shot:v2    # 이전 라이트(v2) 검수 스크린샷 — downloads/darakbang-web-*-v2.png
```

## 0. 디자인 — 밤의 다락방 (v3 다크모드 유지 · v4 운세 세분화)

**v4**는 v3의 다크모드 토큰(`#12192E` 카드 · 골드 헤어라인 · 달빛 크림 글자)을 그대로 두고,
운세를 **10종 주제 카드**로 세분화하고 **12간지 캐릭터**를 얹은 버전입니다.

- 상품 카드: **모바일 2열 / 데스크톱 4열**(마지막 줄은 가운데 정렬 — 4·4·2 대칭), 카드마다
  양피지 메달 안에 12간지 캐릭터, 좌측 상단 `인기·추천·NEW!` 칩, 우측 상단 `1구슬/10구슬` 칩,
  두 줄 후킹 문구, 하단 `일부는 무료 / 점수는 무료` 필 배지 + 금액.
- 원국(무료 결과)의 **띠 안내 카드**가 해당 띠의 캐릭터를 보여 줍니다(원숭이띠 → 원숭이 캐릭터, 말띠 → 말 캐릭터 …).
- 이름을 가진 캐릭터는 대표 캐릭터 생쥐 **자니** 하나뿐입니다 — 12간지 첫 번째 쥐, 소원을 읽어 주는 다락방 친구.
  나머지 11띠는 별명 없이 **`원숭이띠`·`말띠`** 처럼 기본 띠 이름으로만 표기합니다(일러스트는 그대로).

## 0-1. 디자인 — 밤의 다락방 (v3 · 다크모드)

딥 미드나잇 네이비 바탕(`#0B1020` · `#12192E` · `#18223D`)에 달빛 크림 글자(`#F5EFE2`)와
샹페인 골드 포인트(`#E6C378`), 은은한 코발트 글로우(`#4E7AD9`)를 얹은 밤하늘 톤.
헤더 · 히어로 · 상품 카드 · FAQ · 푸터 · 결제 모달 · 결과 리포트 시트까지 전 화면이 다크모드입니다.

남색 잉크 손그림 일러스트(다락방 창 · 자니)는 흰 종이를 그대로 쓰면 다크 화면에서
'흰 스티커'처럼 떠 보이므로 `scripts/make-night-art.py` 로 두 판을 만들어 씁니다.

- `*-night.webp` : 흰 종이를 양피지(`#F2E9D5`)로 옮긴 판
- `*-cut.webp`   : 종이를 투명으로 뽑아낸 판 — 양피지 카드 · 메달 위에 얹어 카드 그라데이션이 비치게

히어로 메인 비주얼은 **달빛을 받은 양피지 타로 카드**(골드 헤어라인 + 외곽 글로우) 안에 얹었고,
헤더 마크 · 원국 안내 카드 · 오늘의 운세 카드 · 결제 진행/완료 화면의 자니도 같은 양피지 언어를 씁니다.
12간지 캐릭터 12종은 `scripts/make-zodiac.py` 로 시트(`attachments/2026-11-19/IMG_3760-*.jpg`)에서 잘라
`public/images/zodiac/*-cut.webp` 로 저장합니다(칸 위 손글씨 라벨·잡점은 걷어내고 남색 잉크만 투명 배경으로).
파일 이름은 동물 이름(`ox`·`tiger`·`rabbit`·`dragon`·`snake`·`horse`·`sheep`·`monkey`·`rooster`·`dog`·`pig`)이고,
쥐만 대표 캐릭터 이름 `jani` 를 씁니다.
리포트 시트는 다크 양피지 카드 위 크림 글자로 본문 대비 12:1 이상을 유지합니다(AA 4.5:1 충족).
원국 표의 띠·일주 동물 표시는 만세력 엔진 결과를 그대로 따릅니다.

계산 규칙
- **년주**: 입춘 시각 기준. **월주**: 24절기 중 '절' 시각 기준. **일주**: 60갑자 연속(1992-10-15 = 갑자 기준점).
- **시주**: 진태양시 보정 후 시지. 표준시 연혁 반영 —
  1908~1911·1954.3.21~1961.8.9은 UTC+8:30(보정 0분), 1987·1988 서머타임은 −90분, 그 외 −30분.
  23시 이후는 야자시로 다음 날 일주 적용.
- **음력**: 한국천문연구원 음양력 데이터(korean_lunar_calendar) 기반 테이블. 1900~2049 지원.
- **궁합 관계표**: 천간·지지 쌍은 각 표의 순서로 정규화해 합·충·형·원진·파를 찾습니다. 한글 코드포인트 정렬로 '진술'·'오미' 같은 쌍을 놓치던 문제를 고쳤습니다(2026-11-18).
- **자미두수**: 음력 월·일·시로 명궁/신궁 → 명궁 간지 납음으로 오행국 → 借數로 자미성 → 14주성·좌보/우필/문창/문곡/천괴/천월/녹존/천양/타라 배치.

### 최애궁합 (6글자 연인 궁합)

`#/product/bias` — 최애(아이돌·배우)의 **이름 + 생년월일**만 넣으면 내 사주와 겹쳐 연인 궁합을 읽습니다.
연예인은 생시가 공개되지 않는 경우가 대부분이라 **`태어난 시간을 몰라요`가 기본값**이고,
그때는 시주 없이 **년·월·일주 6글자**(일간·일지·띠·오행)로 계산합니다. 시간을 넣으면 시주까지 반영합니다.

- 무료 맛보기: 최애 궁합 점수(100점) · "연인이 된다면?" 케미 한 줄 · 일주·오행 케미 요약
- 유료(1구슬·990원) 5장: ① 아이돌·배우와 연인이 된다면? 우리의 첫인상 & 설렘 포인트
  ② 최애가 실제로 끌리는 연애 스타일 vs 나의 매력 포인트 ③ 서로 채워주는 오행 케미 & 조심할 엇박자
  ④ 2026~2027 두 사람의 시너지가 가장 빛나는 달 ⑤ 오늘의 다락방 처방(행운 색·숫자·팁)
- 점수는 `computeCompat`의 4축(끌림·오행 보완·소통·생활)에 **설렘 축**을 더해 가중 평균하고,
  최애 이름은 조사(와/과 · 은/는 · 이/가)까지 맞춰 문장에 넣습니다.
- 2026~2027 스물네 달은 두 사람의 월건·십성·월지 합충을 겹쳐 점수화합니다. 같은 입력이면 언제나 같은 점수·같은 달입니다(`tests/bias.test.mjs`).
점수는 모두 `computeChart` / `computeJami` 결과에서 결정론적으로 계산됩니다(같은 입력 = 같은 점수).

구슬 충전: 1구슬 990원 · 5구슬 4,900원 · 10구슬 9,900원.

**구슬의 목적·용도 (토스페이 심사 요구)** — 구슬은 사주보는 3층 다락방의 유료 사주 리포트를 열람하기 위한
전용 이용권(1구슬 = 990원)입니다. 구슬로 결제 가능한 상품은 정통 사주 해설(1구슬) · 1:1 사주 궁합(1구슬) ·
최애궁합(1구슬) · 신년운세(1구슬) · 대운 풀이(1구슬) · 평생 종합 리포트(10구슬) 등 사이트 내 모든 유료
사주 리포트(연애운·재회운·재물운·자미두수 심층 포함)입니다. 문장은 `config/products.js`의
`BEAD_PURPOSE`·`BEAD_USABLE_LIST` 하나만 고치면 충전 모달 · FAQ · 상품 안내 · 이용약관 · 환불규정에 함께 반영됩니다.

**유효기간·환불 (토스페이 심사 요구)** — 리포트 열람 가능 기간과 구슬 유효기간은 모두 **결제일로부터 1년 이내**입니다
(이용약관 제5조·제7조, 환불규정 1항). 열람 전에는 결제일로부터 7일 이내 전액 환불, 5구슬·10구슬 묶음은
일부 사용 후에도 1년 이내에 **남은 미사용 구슬 부분 환불**이 가능합니다(이용약관 제8조 4항, 환불규정 3항).

### PG 연결 방법 (2026-11-19 토스페이 V2 실연동)

```js
export const KEYS = {
  portone: {
    storeId: 'store-5ad01159-8552-4b67-a6f7-474a40a9fc9a',
    channelKey: 'channel-key-d1b42578-273f-4a86-9a75-3af09b467930', // 토스페이 V2 · MID IMPTsister01
    channelKeyKakao: '', // 카카오페이 전용 채널 (심사 후)
    channelKeyCard: '',  // 신용·체크카드(KPN) 채널 (심사 후)
  },
};
```

- 키가 채워져 있으므로 `isTestMode()` 는 **false = 실결제 모드**입니다. 결제 금액이 실제로 청구됩니다.
- **결제 수단**: 토스페이만 실연동(기본 선택). 신용·체크카드(KPN)·카카오페이는 PG 심사 중이라
  `PAY_METHODS` 의 `ready: false` 로 비활성 표시되고, 모달에 "심사 중" 배지와 안내 문구가 뜹니다.
  심사가 끝나면 콘솔에서 채널을 추가해 `channelKeyCard`/`channelKeyKakao` 를 채우고 `ready: true` 로 바꾸면 됩니다.
- **요청 규격(포트원 V2)**: `payMethod: 'EASY_PAY'` + `easyPay: { easyPayProvider: 'TOSSPAY' }`,
  `currency: 'CURRENCY_KRW'`, `storeId`·`channelKey`·`paymentId`·`orderName`·`totalAmount`.
  SDK 는 `https://cdn.portone.io/v2/browser-sdk.js` 를 처음 결제 때 동적으로 불러옵니다.
- **모바일**: 대부분 리디렉션 방식이라 `redirectUrl`(`…/darakbang-saju-web/?pay=portone`)로 돌아오고,
  복귀 쿼리의 `paymentId`·`code`·`message` 로 승인/취소를 가릅니다. 결제 직전 정보는
  localStorage(`darakbang.pay.pending`)에 임시 저장해 복귀 시 이어받고 바로 지웁니다.

### 결제 검증(서버)

`payment.js` 의 `VERIFY_ENDPOINT` 가 비어 있으면 **서버 없이 동작하는 정적 배포 모드**로,
포트원 결제창이 오류 코드 없이 `paymentId`·`txId` 를 돌려준 경우 승인으로 처리해 리포트 잠금을 해제합니다.
서버를 붙일 때는 `VERIFY_ENDPOINT` 만 채우면 됩니다 —
`GET {VERIFY_ENDPOINT}?paymentId=…&amount=…` 응답이 `{ "ok": true }` 이면 승인.
(서버에서는 `POST https://api.portone.io/payments/{paymentId}` 로 `status === 'PAID'` 와 `amount.total` 확인)

### 테스트 결제 모드

키가 비어 있으면 결제창 → 승인(1.1초 시뮬레이션) → 승인번호 발급 → 리포트 잠금 해제까지 실제와 동일하게 동작합니다.
결제 기록은 브라우저 localStorage 에만 남고, 화면에도 "TEST · PG 테스트 결제 모드" 로 표시됩니다.
