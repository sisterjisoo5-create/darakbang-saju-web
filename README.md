당근 비즈프로필(`사주보는 3층 다락방`)과 **완전히 분리된** 990원 온라인 사주 전용 정적 웹앱입니다.
가입 없이 생년월일시만 넣으면 만세력·자미두수로 원국을 계산해 무료 맛보기를 보여주고,
유료 리포트(1구슬 = 990원)는 맛보기 후 잠금 해제 방식으로 엽니다.

## 0. 디자인 — 밤의 다락방 (v3 다크모드 유지 · v4 운세 세분화)

**v4**는 v3의 다크모드 토큰(`#12192E` 카드 · 골드 헤어라인 · 달빛 크림 글자)을 그대로 두고,
운세를 **10종 주제 카드**로 세분화하고 **12간지 캐릭터**를 얹은 버전입니다.

- 상품 카드: **모바일 2열 / 데스크톱 4열**(마지막 줄은 가운데 정렬 — 4·4·2 대칭), 카드마다
  양피지 메달 안에 12간지 캐릭터, 좌측 상단 `인기·추천·NEW!` 칩, 우측 상단 `1구슬/10구슬` 칩,
  두 줄(최애궁합 카드는 세 줄) 후킹 문구, 하단 `일부는 무료 / 점수는 무료` 필 배지 + 금액.
- 원국(무료 결과)의 `내 여덟 글자` 헤더가 **일주 동물 이름(예: 붉은 소)** 을 금빛 배지로 강조하고, 그 아래 `띠 × 일주 동물 · 시` 줄과 **오행 온도 요약(따뜻 25.6°C 사주)** 을 차례로 붙입니다. 4주 카드 다음은 곧바로 `오행 온도` 섹션입니다.
- 헤더 오른쪽 원형 배지는 **자니 아바타(두둥실 float 모션)** 이고, 배지 안쪽 하단에 그 띠의 한 줄 키워드(예: `감정을 짚어 주는 공감`)가 들어갑니다(12띠 키워드 모두 390px에서도 잘리지 않음 — `npm run check:free`).
- 무료 원국의 `12띠 × 일주 동물` 은 **60일주 팩폭 카드**(별명·한 줄 캐치프레이즈·찔리는 내 특징 3·남이 보는 나 vs 진짜 나)를 무료로 보여 주고, 144조합 전체 풀이(첫인상·반전 매력·관계·이성 어필 포인트·연애 팁)는 **`12띠 X 일주동물`(1구슬 · 990원)** 유료 상품으로 엽니다.
  카드에는 **`공유용 이미지 저장`** 버튼이 있어 카톡·인스타에 올릴 **한 장짜리 PNG**(위 제목·아래 작은 다락방 이름)로 바로 저장됩니다(2026-11-22).
  카드 위 **겉·속 캐릭터 두 개는 크림색 원형 배지**(히어로 자니 배지와 같은 크림 톤 + 금빛 테두리, `.zi-teaser__badge`) 위에 얹습니다 — 남색 선화가 어두운 카드에 묻히지 않고, 화면과 저장한 PNG 가 같은 모양으로 나옵니다(2026-11-22).
- 무료 원국의 자미두수 카드는 **명궁 `(나의 캐릭터)` · 신궁 `(나이가 들수록 마음이 기우는 방향)` 두 자리만** 보여 주고, 부처궁(배우자 자리)·12궁 전체는 **`자미두수 심층`(1구슬 · 990원)** 으로 안내합니다.
- 홈의 프리뷰 4카드는 모바일에서도 **2×2 콤팩트 그리드**로 들어가 한 화면에서 한눈에 읽힙니다.
- 이름을 가진 캐릭터는 대표 캐릭터 생쥐 **자니** 하나뿐입니다 — 12간지 첫 번째 쥐, 소원을 읽어 주는 다락방 친구.
  나머지 11띠는 별명 없이 **`원숭이띠`·`말띠`** 처럼 기본 띠 이름으로만 표기합니다(일러스트는 그대로).

## 0-1. 디자인 — 밤의 다락방 (v3 · 다크모드)

딥 미드나잇 네이비 바탕(`#0B1020` · `#12192E` · `#18223D`)에 달빛 크림 글자(`#F5EFE2`)와
샹페인 골드 포인트(`#E6C378`), 은은한 코발트 글로우(`#4E7AD9`)를 얹은 밤하늘 톤.
헤더 · 히어로 · 상품 카드 · FAQ · 푸터 · 결제 모달 · 결과 리포트 시트까지 전 화면이 다크모드입니다.

남색 잉크 손그림 일러스트(다락방 창 · 자니)는 흰 종이를 그대로 쓰면 다크 화면에서
'흰 스티커'처럼 떠 보이므로 `scripts/make-night-art.py` 로 두 판을 만들어 씁니다.

- `*-night.webp` : 흰 종이를 양피지(`#F2E9D5`)로 옮긴 판
- `*-cut.webp`   : 종이를 투명으로 뽑아낸 판 — 양피지 카드 · 메달 위에 얹어 카드 그라데이션이 비치게

히어로 메인 비주얼은 **달빛을 받은 양피지 타로 카드**(골드 헤어라인 + 외곽 글로우) 안에 얹었고,
헤더 마크 · 내 여덟 글자 자니 원형 배지 · 결제 진행/완료 화면의 자니도 같은 양피지 언어를 씁니다.
(`다락방 자니가 읽어주는 오늘의 운세` 카드는 무료 원국에서 내려 두고, 최애궁합 화면에 붙일 때 다시 쓸 수 있도록 코드·CSS를 남겨 두었습니다.)
12간지 캐릭터 12종은 `scripts/make-zodiac.py` 로 시트(`attachments/2026-11-19/IMG_3760-*.jpg`)에서 잘라
`public/images/zodiac/*-cut.webp` 로 저장합니다(칸 위 손글씨 라벨·잡점은 걷어내고 남색 잉크만 투명 배경으로).
파일 이름은 동물 이름(`ox`·`tiger`·`rabbit`·`dragon`·`snake`·`horse`·`sheep`·`monkey`·`rooster`·`dog`·`pig`)이고,
쥐만 대표 캐릭터 이름 `jani` 를 씁니다.
리포트 시트는 다크 양피지 카드 위 크림 글자로 본문 대비 12:1 이상을 유지합니다(AA 4.5:1 충족).
원국 표의 띠·일주 동물 표시는 만세력 엔진 결과를 그대로 따릅니다.

- **결제 수단**: 토스페이만 실연동(기본 선택). 신용·체크카드(KPN)·카카오페이는 PG 심사 중이라
  `PAY_METHODS` 의 `ready: false` 로 비활성 표시되고, 모달에 "심사 중" 배지와 안내 문구가 뜹니다.
  심사가 끝나면 콘솔에서 채널을 추가해 `channelKeyCard`/`channelKeyKakao` 를 채우고 `ready: true` 로 바꾸면 됩니다.
- **요청 규격(포트원 V2)**: `payMethod: 'EASY_PAY'` + `easyPay: { easyPayProvider: 'TOSSPAY' }`,
  `currency: 'CURRENCY_KRW'`, `storeId`·`channelKey`·`paymentId`·`orderName`·`totalAmount`.
  SDK 는 `https://cdn.portone.io/v2/browser-sdk.js` 를 처음 결제 때 동적으로 불러옵니다.
- **모바일**: 대부분 리디렉션 방식이라 `redirectUrl`(`…/darakbang-saju-web/?pay=portone`)로 돌아오고,
  복귀 쿼리의 `paymentId`·`code`·`message` 로 승인/취소를 가릅니다. 결제 직전 정보는
  localStorage(`darakbang.pay.pending`)에 임시 저장해 복귀 시 이어받고 바로 지웁니다.

### 결제 검증(서버)

`payment.js` 의 `VERIFY_ENDPOINT` 가 비어 있으면 **서버 없이 동작하는 정적 배포 모드**로,
포트원 결제창이 오류 코드 없이 `paymentId`·`txId` 를 돌려준 경우 승인으로 처리해 리포트 잠금을 해제합니다.
서버를 붙일 때는 `VERIFY_ENDPOINT` 만 채우면 됩니다 —
`GET {VERIFY_ENDPOINT}?paymentId=…&amount=…` 응답이 `{ "ok": true }` 이면 승인.
(서버에서는 `POST https://api.portone.io/payments/{paymentId}` 로 `status === 'PAID'` 와 `amount.total` 확인)

## 9. 리포트 이미지 저장 (2026-11-22)

리포트 화면의 `리포트 인쇄 · PDF` 버튼을 **`이미지 저장`** 으로 바꿨습니다. 누르면 리포트 카드가
**PNG(2배 해상도)** 로 만들어져 핸드폰은 사진첩으로, PC 는 파일로 저장됩니다.

- 렌더러: `html-to-image`(`toPng`)를 **번들 의존성**으로 넣었습니다(CDN 없음 — CSP·CORS·오프라인에서 동작).
  브라우저가 실제로 그린 결과를 SVG `foreignObject` 로 복제하므로 자미두수 명반판(SVG·표·배지)·그라디언트·웹폰트가 화면 그대로 담깁니다.
- 캡처 대상: 리포트 화면의 `#report-capture`(모든 990원 12종·평생 종합 리포트가 같은 `productView` 를 씁니다).
  버튼·영수증·하단 조작 바(`data-capture-skip`)는 이미지에서 빠집니다.
- 캡처 모양: 화면 크기와 상관없이 **폰 카드(430px 폭)** 로 다시 그립니다(`.capture-page` 안에서 720px 이하 스타일 고정).
- 길면 자른다: 카드 경계에서 여러 장으로 나눕니다 — 핸드폰은 한 장 1,900px, PC 는 3,800px 까지 — 2배 해상도로 구워도 iOS 캔버스 한계(iOS 18 미만 4,096px) 안입니다.
  넘칠 때는 `safeRatio` 로 배율을 낮추고, 사파리가 빈 이미지(`data:,`)를 돌려주면 배율을 낮춰 다시 굽습니다(`capturePage`).
- 저장 동선: `navigator.canShare({files})` 가 되면 `navigator.share` 로 공유 시트(사진첩 저장)를 열고,
  사용자가 닫으면(`AbortError`) **오류로 처리하지 않습니다**. 지원하지 않는 환경은 `<a download>` 로 내려받고,
  공유가 막힌 경우(제스처 만료 `NotAllowedError`)에는 미리보기 모달에서 다시 저장할 수 있습니다.
- 버튼은 누르는 동안 `저장 중...`(`aria-busy`)으로 바뀌고, 끝나면 토스트로 알립니다.
- **완성된 결과지로 담기(2026-11-22 보강)**: 장마다 위에 **미니 헤더**(리포트 제목 + 생년월일시), 아래에 **브랜딩(`사주보는 3층 다락방`) + 페이지 번호(`1 / 3` … `3 / 3`)** 를 넣습니다. 한 장짜리는 번호를 생략합니다.
  여백은 26·18·22px, 카드 사이는 16px 로 넉넉하게 두고, 화면의 큰 제목 줄(`.result-head`)은 저장본에 넣지 않습니다(미니 헤더가 그 자리를 대신).
  장 나눔은 **먼저 카드를 얹어 보며 끊을 자리를 정하고(1단계), 그 묶음대로 다시 그려 굽습니다(2단계)** — 카드가 반으로 잘리지 않고, 마지막 장에 어정쩡한 여백이 남지 않습니다. 한 카드가 한 장보다 크면 자르지 않고 통째로 담고 배율만 낮춥니다.

- **02 タイプ** — 1번째 글자는 일간 음양(S 表に出す / M 内に秘める), 나머지 3글자는 문항(布教T·静観Q / 課金K·手間J / 現場F·おうちH).
  16타입 모두 `取扱説明書` 3줄·オタ友·取扱注意를 갖는다. 결과는 영수증(レシート) 스타일 — 날짜·성분(오행 개수)·財布の危険度.
- **03 重め恋愛** — 입력은 **생년월일 하나**(三柱·시각 없음). 결과는 ① 년지 12띠 동물 타입명 + 일러스트(`public/images/zodiac/` 12컷, 결과 화면은 表·裏 두 마리)
  ② `愛の重さ` 42~99% 게이지 + 6단계 라벨(`無限重`·`ヘビー級`·`かなり重め`·`重め`·`ふつう寄り`·`軽やか寄り`) ③ 表(년지: 남에게 보이는 모습) vs 裏(일지: 둘이 됐을 때) 갭 한 줄 +
  `重めの癖` 3개(표 2 + 이 1) + `ここが沼る` + `相性のいい動物`(六合·三合) + `重すぎ注意`(冲) + `重さのトリセツ`. 12동물 모두 이름·캐치·표/이·습관 2·매력·처방을 갖고,
  년지와 일지가 같으면 `表も裏も同じ動物` 전용 문장. 무게 %는 동물 하한 + 일간 + 십성(인성·관성·겁재·상관·식신) + 년지·일지 관계로 결정론적으로 계산(77% 중심, 실측 55~97%).
  카드 PNG는 12띠 그림을 미리 읽어 크림 메달에 얹고(로드 전이면 한자 메달로 대체), 表/裏 알약 + % 게이지 + 갭 한 줄 + 癖 3 + 相性 + 沼る + トリセツ를 담는다.
